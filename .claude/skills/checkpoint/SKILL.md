## User Input

```text
$ARGUMENTS
```

Длинная сессия дорожает: каждый ход перечитывает весь контекст (жжёт лимит).
Экономь через контрольные точки на границах **логических пачек** подзадач (НЕ
каждого `Tnnn` — иначе слишком частые паузы).

## Шаги

- **Держи тяжёлую работу в субагентах команды flow** (`flow-builder`/`flow-finder`/`flow-expert`):
  их контекст живёт в своём окне и не оседает у тебя — в основной контекст идёт только отчёт
  (потолок отчёта ≤ ~2k токенов зашит в контракт агентов). Главный рычаг экономии.
- **Триггер по бюджету контекста (прокси).** Точный размер контекста в токенах модели
  не виден — ориентируйся на прокси-эвристику: сколько тяжёлых `tool_result`/отчётов
  субагентов/крупных чтений накопилось с прошлого сброса. Ориентиры оркестратора:
  **~80k — рабочий потолок** (норма, ничего не делаем); **~120k — мягкий триггер** →
  сделать checkpoint на ближайшей границе логической пачки; **~160k — жёсткий предел** →
  сброс немедленно, не дожидаясь границы пачки. Компактизация рвёт 5-минутный prompt-cache
  префикса — потому не чаще, чем диктует бюджет (не после каждого `Tnnn`).
- **Session flush (Столп 2 — durable в банк, эфемерное чистим).** Прежде чем уступить ход:
  1. **Persist** durable-знание сессии в Memory Bank по регламенту ([[memory-regimen]]):
     `tasks.md` `[X]` (на фиче-ветке) + `projects/active-context.md` и профильная спица
     (`decisions`/`roadmap`) **на `develop`**; атомизация при over-budget. Правило:
     что не влилось в банк — потеряется при сбросе, поэтому durable выноси ЗДЕСЬ.
  2. **Verify**: `python3 scripts/check_memory_links.py` (ссылки/сироты); при правках банка —
     `mb_recall.py rebuild` (индекс регенерируется).
  3. **Cleanup эфемерного**: убери сессионные/кэш-артефакты —
     `.claude/code-analysis/*.json` (`last-run-log.json`/`import-graph.json`),
     `memory-bank/.recall-index.json`, session-scratch. Durable (`memory-bank/**`,
     `.claude/agents|skills`, `specs/**`) НЕ трогай. Если в проекте есть свой скрипт
     очистки — используй его. Plan-файлы (`~/.claude/plans/`) — за харнессом, не наша цель.
- **После flush:** состояние вынесено, эфемерное убрано — контекст можно сбросить без потерь.
  Выведи маркер и **уступи ход** (по умолчанию), не начиная следующую пачку в том же контексте:

  > 🧹 **Точка сброса.** Пачка закрыта, состояние в `tasks.md`/memory-bank. Безопасно
  > `/compact` (сжать) или `/clear` + `/flow <цель>` (сбросить полностью — дешевле по
  > лимиту). Скажи «продолжай», если сброс не нужен.

- `/clear` + свежий `/flow` сбрасывает ВЕСЬ накопленный контекст (максимум экономии);
  `/compact` оставляет резюме. Оба безопасны — состояние durable в `tasks.md`/memory-bank.
- **Скилл САМ `/compact` не вызывает** (это действие харнесса, тула нет) — он только
  доводит до безопасной точки и уступает ход; сжатие/сброс запускает пользователь.

**Дальше:** `/compact`, или `/clear` + `flow <цель>`, либо «продолжай» (по решению
пользователя) — сам скилл ничего дальше не запускает.
