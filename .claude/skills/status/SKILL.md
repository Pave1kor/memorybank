Ты — **дашборд**. Задача — дать пользователю целостную картину «где мы».
**Только отчёт: субагентов команды flow (`flow-*`) не спавни, работу не запускай, код не правь.**
Единственные разрешённые сайд-эффекты — git-синхронизация (шаг 0): stash, checkout
develop, fetch/pull. Файлы проекта и Memory Bank ты не редактируешь.

## Шаг 0 — привести дерево к актуальной ветке `develop`

`develop` — актуальная ветка: все задачи/фичи/идеи/долги актуальны именно в ней.

1. **Грязное дерево → авто-stash.** Если есть незакоммиченные изменения — запомни текущую
   ветку `<X>` и убери их: `git stash push -u`.
2. **Переключись:** `git checkout develop`.
3. **Подтяни весь проект с сервера:** `git fetch --all --prune`, затем `git pull --ff-only`.
4. Если стэшил — **сам stash НЕ применяй на develop.** Скажи об этом в конце (см. ниже).

## Шаг 1 — Memory Bank (источник истины на develop)

**Актуальный Memory Bank живёт ТОЛЬКО на `develop`** — поэтому Шаг 0 и приводит дерево к ней.
Записи банка на фиче-ветках устаревшие/расходятся; читай и опирайся на версию `develop`.
Банк организован по PARA (`memory-bank/projects/`/`areas/`/`resources/`/`archive/`) — читай
ТОЛЬКО нужную заметку под задачу, не всё подряд; `archive/` по умолчанию НЕ грузи (это свёрнутая
история, нужна лишь для деталей закрытой фичи). Выбор релевантных заметок — через
`py scripts/mb_recall.py query "<тема>"` (Windows) / `python3 scripts/mb_recall.py query "<тема>"`
(POSIX), shortlist top-k; фолбэк при недоступном python — ручной выбор по README-роутеру.
Прочитай `memory-bank/projects/active-context.md`
(+ при нужде `memory-bank/projects/roadmap.md`). Дай сводку в 2–4 строки: на чём стоим, что в
работе, что незакрыто.

## Шаг 2 — собрать и показать (компактно, таблицами/списками, без дампов)

1. **Ветки/синхронизация.** develop относительно `origin/develop` (ahead/behind после pull —
   в норме 0). Перечисли локальные фиче-ветки и их ahead/behind к develop; `git worktree list`
   (если есть).
2. **Активная фича.** Из `.specify/feature.json` → `specs/<feature>/tasks.md`: посчитай `[X]`
   сделано / `[ ]` осталось, сгруппируй по срезам/секциям. Покажи **следующую незакрытую
   задачу** (первую разблокированную по разделу «Зависимости»).
3. **Все фичи.** Перечисли `specs/*/` c `tasks.md`: номер+имя, краткий прогресс `[X]`/`[ ]`,
   пометь активную; какие незакрыты.

   > **Грабли (обязательно).** Артефакт фичи — ТОЛЬКО `specs/<NNN>-<slug>/tasks.md`. Никогда
   > не ищи `tasks.md` вслепую по всему дереву (`grep -r`, `ls-tree | grep tasks.md`) — так
   > цепляется **шаблон команды** `.claude/skills/speckit.tasks.md` (это НЕ артефакт фичи, а
   > описание speckit-фазы). И при `head -1` по нескольким совпадениям берётся не та фича
   > (напр. `009-…` вместо нужного номера). Всегда якори паттерн номером фичи:
   > `specs/<NNN>-*/tasks.md`. Артефакты незалитых фич живут на их ветках — читай через
   > `git show origin/feat/<NNN>-<slug>:specs/<NNN>-*/tasks.md`, а не из рабочего дерева
   > `develop` (там их ещё нет).
4. **Долги.** `memory-bank/projects/roadmap.md` (секция «Долги») + незакрытые «Открытые
   развилки/уборка» из `memory-bank/projects/active-context.md` — пункты БЕЗ `✅`/`~~зачёркнуто~~`.
   У каждого: якорь `[slug]` + краткая суть. Закрытые долги (для истории) — `memory-bank/
   archive/roadmap-closed.md`, грузи только по явному запросу деталей.
5. **Идеи.** `memory-bank/projects/roadmap.md` (секция «Идеи (отложено)») — пункты БЕЗ `✅`. У
   каждой: якорь `[slug]` + суть + условие внедрения.
6. **Сессионные артефакты** (Столп 2 — durable=Memory Bank, эфемерное удаляется). Проверь наличие
   эфемерных/кэш-файлов: `.claude/code-analysis/last-run-log.json`, `import-graph.json`,
   `memory-bank/.recall-index.json`, `~/.claude/plans/*.md`. Залежались → отметь одной строкой и
   подскажи `/checkpoint` (сливает durable-знание в банк, ЗАТЕМ чистит эфемерное). **Сам НЕ удаляй**
   (read-only). Durable (`memory-bank/**`, `.claude/agents|skills`) не трогаем.
