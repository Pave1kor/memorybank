## User Input

```text
$ARGUMENTS
```

Ты записываешь пункт (долг или идею) в roadmap — **не начинаешь над ним работать**.

## Шаги

1. Убедись, что ты на `develop` (roadmap — источник истины там). Грязное дерево —
   застэшь/закоммить текущее (см. git-рецепты в [[commands]], раздел «Разведка перед
   работой»).
2. Внеси пункт в `memory-bank/projects/roadmap.md` (ТОНКИЙ ИНДЕКС): долг → секция «Долги
   (в работе / открыто)», идея → «Идеи (отложено)». Стабильный якорь `[slug]` (короткий
   kebab), суть + условие внедрения/«как чинить». **Без дублей** — похожий пункт есть →
   дополни его, не плоди новый. Атомизация по объёму (регламент — [[memory-regimen]]):
   - **Короткий** (одна мысль, ≤~3 строк) — инлайн одной строкой в индексе.
   - **«Толстый»** (диагноз/развилки >~5 строк) — спицей: `projects/ideas/<slug>.md`
     (идея) / `projects/debts/<slug>.md` (долг) + строка-указатель `**[[slug]]** — суть`
     в индексе (без указателя = спица-сирота, падает `check_memory_links.py`).
3. Закоммить на `develop` и `git push origin develop` (рецепт «Прямо на `develop`» в
   [[commands]]). Работу НЕ запускаешь.

**Дальше:** записано; работа не начата — `flow <slug>`, если решите взять пункт в
работу сейчас.
