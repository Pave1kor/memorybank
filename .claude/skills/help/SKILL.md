# Воркфлоу проекта — оркестратор + атомарные глаголы

Единый процесс ведения работы через ролевой тиринг моделей. `/flow` — оркестратор
верхнего уровня; под капотом он вызывает атомарные скиллы-глаголы, которые можно
звать и напрямую для точечной операции. Полный реестр — каталог
`memory-bank/resources/commands.md` (`[[commands]]`): все скиллы/скрипты/git-рецепты
+ канонические последовательности для подсказки «Дальше:». Скилы версионируются в
репо (`.claude/skills/`).

## Роли — единая команда flow (жёсткое разделение)

Одна команда субагентов `flow-*`, общая для dev-воркфлоу и ревью-каскада `/ca-review`. Модель
оркестратора — сессии (`/model`, не пиннится); модели спавнимых ролей зашиты в `.claude/agents/flow-*.md`.

| Роль | Модель | R/W | Делает |
|------|--------|-----|--------|
| Оркестратор | сессии (`/model`) | — | сессия `/flow`: speckit-фазы, решения, синтез, вопросы. Код руками не пишет. |
| `flow-router` | Haiku | RO | триаж diff'а → подсистемы/risk/зоны (стадия 1 ревью-каскада). |
| `flow-finder` | Sonnet | RO | scoped research кода/данных ИЛИ поиск дефектов. Развилки поднимает. |
| `flow-reviewer` | Sonnet | RO | свод + критика находок ревью-каскада. |
| `flow-advocate` | Sonnet | RO | состязательный recall (gated) в ревью-каскаде. |
| `flow-expert` | Opus | RO | глубокая верификация / трудный read-only research. |
| `flow-builder` | Sonnet | R/W | реализация по `tasks.md`, тесты до зелёного. НЕ коммитит. |

## `/status` — дашборд (read-only)

Приводит дерево к актуальной ветке `develop` (грязное дерево → авто-`git stash`, потом
`checkout develop`), тянет весь проект с сервера (`git fetch --all --prune` + `git pull`),
изучает Memory Bank и показывает целостную картину, файлы не меняя:
- сводка Memory Bank (`projects/active-context.md`) — «где мы»;
- активная фича + прогресс по `tasks.md` + следующая задача;
- все фичи (`specs/*`) с прогрессом + фиче-ветки (ahead/behind к develop) + worktree'ы;
- открытые **долги** и **идеи** (`projects/roadmap.md`, секции «Долги»/«Идеи») с якорями `[slug]`.

Если что-то застэшил — в конце напомнит, как вернуть (`git checkout <ветка> && git stash pop`).

## `/flow <аргумент>` — сделать работу (оркестратор)

Единая точка входа. По аргументу выбирает путь:

| Аргумент | Что делает |
|----------|------------|
| _пусто_ | Продолжить активную фичу (реализация по `tasks.md` до конца/развилки). |
| `<название/описание>` | Найти цель (фича по имени · долг · идея по `[slug]`) и работать над ней: нет спеки и нетривиально → speckit-цикл; есть задачи → реализация; мелочь → сразу `flow-builder`. |
| `new <описание>` | Завести НОВУЮ фичу: номер + ветка (или worktree), speckit-цикл (`specify→clarify→plan→tasks→analyze`), сделать активной. Реализацию не начинает. |
| `запиши долг: …` / `запиши идею: …` | Записать пункт в `projects/roadmap.md` (секция «Долги» · «Идеи») на develop с якорем `[slug]` и запушить. Работу не запускает. |

Умеет **переключаться на ветку цели**, если незакрытая задача — на другой ветке.
По окончании работы (цель закрыта, тесты зелёные, развилок нет) вызывает `/publish`
(коммит → мердж в `develop` → обновление Memory Bank + CLAUDE.md → пуш). Конфликт
слияния — остановка и вопрос.

**Дальше:** зависит от пути — speckit-цепочка / `implement` / `/checkpoint` / `/publish`
(см. каталог `[[commands]]`, «Канонические последовательности»).

## Атомарные глаголы (точечный вызов)

`/flow` под капотом раздаёт работу этим скиллам — их можно звать и напрямую, минуя
оркестратор, для одной конкретной операции:

| Скилл | Назначение | Когда звать |
|-------|-----------|-------------|
| `/publish` | Завершение+публикация цели: ревью-гейт → Memory Bank → коммит → мерж feat→develop → пуш | Цель доведена, тесты зелёные, развилок нет |
| `/review-gate` | scope-aware ревью (узкий → `/code-review`, широкий/арх-зоны → `/ca-review` каскад) + `/security-review` если чувствительно + триаж | Перед `/publish`, либо отдельно проверить текущий дифф |
| `/ca-review [ref]` | cost-aware мультиагентный каскад команды flow на диффе (широкий/арх-зоны) | Широкий дифф, где нужен бюджет контекста; сам по себе или из `/review-gate` |
| `/checkpoint` | Вынести состояние в `tasks.md`/Memory Bank, вывести маркер сброса, уступить ход | Закрыта логическая пачка подзадач в длинной сессии |
| `/debt <текст>` | Записать долг/идею в `roadmap.md` (стабильный `[slug]`, без дублей) | Всплыла проблема/мысль не по текущей задаче — зафиксировать на потом, без запуска работы |

Каждый глагол самодостаточен и заканчивается блоком «Дальше:» с явным следующим
шагом. Полные записи (входы, зависимости, типичный следующий шаг) — каталог
`memory-bank/resources/commands.md` (`[[commands]]`), там же — скрипты (`scripts/*.py`)
и git-рецепты (точные команды публикации/мержа).

## Инварианты

- Развилка (архитектура / неоднозначность / конфликт слияния) → всегда вопрос пользователю, не угадывание.
- **Публикует только оркестратор и только по окончании цели** (авто-коммит+мердж+пуш в develop).
  Субагенты (`flow-builder` и др.) mid-task НЕ коммитят. Незавершённую цель в develop не сливают.
- Состояние живёт в `specs/<feature>/tasks.md` + Memory Bank (на develop) → переживает перезапуск сессии.
- Активная фича — поле `feature_directory` в `.specify/feature.json`.

## Типовые сценарии

```
/status                              # где мы: фичи, долги, идеи, что осталось
/flow                                # прогнать активную фичу до конца/развилки
/flow закрой долг [front-lineage]    # взять долг из roadmap и починить
/flow 042                            # переключиться на фичу 042 и продолжить
/flow new единый источник M1 + ресемпл   # завести новую фичу через speckit
/flow запиши идею: WFO на K фолдов    # зафиксировать идею в roadmap
/publish                             # цель доведена — завершить и опубликовать
/review-gate                         # прогнать ревью-гейт на текущем диффе
/checkpoint                          # контрольная точка перед /compact или /clear
/debt запиши долг: front-lineage race condition   # зафиксировать долг напрямую
```

## Где что лежит

- Скилы: `.claude/skills/{flow,status,help,publish,review-gate,checkpoint,debt,ca-review}/SKILL.md`
- Каталог команд: `memory-bank/resources/commands.md` (реестр + канонические последовательности)
- Speckit-машинерия: `.claude/skills/speckit.*.md`
- Агенты команды flow: `.claude/agents/flow-{router,finder,reviewer,advocate,expert,builder}.md`
- Артефакты фич: `specs/<feature>/{spec,plan,tasks}.md`
- Активная фича: `.specify/feature.json`
- Долги/идеи/roadmap: `memory-bank/projects/roadmap.md` (закрытые — `memory-bank/archive/roadmap-closed.md`)
- Курс/контекст: `memory-bank/` (индекс — `README.md`, PARA: `projects/`/`areas/`/`resources/`/`archive/`)
