# Регламент Memory Bank

_Полные правила ведения банка. Читается по требованию (при обновлении банка), не
авто-грузится. Карта файлов и Zettelkasten-механика — в роутере [[README]]._

## Модель контекста: хабы vs спицы

Экономия контекста держится на разделении файлов по тому, **когда за них платят**:

- **Хабы (платим КАЖДУЮ сессию).** `CLAUDE.md` харнесс инъектит в контекст целиком и
  безусловно; README-роутер подтягивает хук `SessionStart`. Харнесс НЕ ходит по `[[links]]` —
  выдаёт файл как есть, ленивая загрузка невозможна. Поэтому хабы держим тонкими (чистые
  указатели) и под бюджетом `check_memory_links.py` — это единственная всегда-платимая
  поверхность. Бюджетируемые хабы: `CLAUDE.md`, `README.md`, `active-context.md`, `roadmap.md`.
- **Спицы (платим ТОЛЬКО при `Read`).** `planned/NNN-*.md`, per-entity долги/идеи, `areas/*`,
  `resources/*`, `archive/*` — грузятся по требованию по ссылке. Их размер не бьёт по каждой
  сессии → **бюджет с них снят** (файла нет в `SIZE_BUDGETS` → не проверяется).

Линчпин экономии: **прополка хаба на закрытии**. Файл-на-сущность экономит контекст только
если закрытые вычищаются из авто-загружаемого хаба; забыл убрать строку — хаб снова монолит.

## Правила

- **Только на `develop`.** Банк — единственный источник истины на `develop`; правь/коммить
  записи там (не на фиче-ветках — расходятся, дают merge-конфликты). spec/plan/tasks фичи — на её ветке.
- **По завершении задачи** обнови затронутые заметки — обычно `[[active-context]]` + одну
  профильную (`[[decisions]]` / `[[blocks]]` / `[[roadmap]]`).
- **Планируемая фича — файл на фичу.** Детали speckit-готовой, но не начатой фичи (диагноз/
  развилки/US) → `projects/planned/NNN-slug.md` (её `specs/` на фиче-ветке, не на `develop` →
  банк-файл = единственный develop-дом; грузить только работая над ней). В `active-context` —
  строка-указатель `→ [[NNN-slug]]`.
- **Долг/идея — атомизировать по мере роста.** Пока `roadmap.md` в бюджете — держать списком
  (одна строка на `[slug]`). «Толстый» пункт (диагноз/развилки > ~5 строк) → `projects/debts/<slug>.md`
  / `projects/ideas/<slug>.md` + строка-указатель в `roadmap.md`. Короткие долги файл не заводят.
- **Архивируй по закрытию — тоже файлом.** Закрыта фича целиком → `planned/NNN-*.md`
  **переезжает** в `archive/features/NNN-slug.md` (переписан как «закрыт»: суть, числа, merge sha),
  строка-указатель в `active-context` → в датированный индекс `archive/index.md`; в
  `active-context` остаётся ≤1 строка «Недавно влитые». Закрытый долг/идея → `archive/roadmap-closed.md`
  или per-entity в `archive/`, из `roadmap.md` убрать. `archive/` не грузится по умолчанию и вне бюджета.
- **`active-context.md` — только «сейчас»:** ветка, активная фича, строки-указатели на планируемые,
  открытые развилки/уборка. Развёрнутые блоки фич сюда НЕ пишем (это долг, схлопывать при касании).
- **Без дублей.** Одна мысль — один файл; меняешь решение — правь существующий пункт. Не
  дублируй то, что есть в коде/гите/`CLAUDE.md` — пиши «почему» и контекст.
- **`CLAUDE.md` держи тонким.** Авто-грузится каждую сессию — durable-детали клади в PARA-заметку,
  в `CLAUDE.md` оставляй выжимку + ссылку.
- **Прогоняй `python3 scripts/check_memory_links.py`** при обновлении банка: целостность `[[links]]`
  (резолв по уникальному basename — следи за коллизиями слагов), бюджет хабов, сверка каталога
  команд. Exit 0 — чисто.
