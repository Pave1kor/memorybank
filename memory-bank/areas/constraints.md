# Инварианты и ограничения

_Заполни под свой проект: правила, которые нельзя нарушать (контракты данных, границы
безопасности, потокобезопасность, детерминизм, изоляция модулей). Эти инварианты — источник для
`.claude/code-analysis/architecture-zones.json` (зоны эскалации ревью) и для конституции
(`.specify/memory/constitution.md`)._

## Инварианты

- **[I-1]** [пример: единый источник настроек; секреты только из env, не в репозитории]
- **[I-2]** [пример: контракт данных X имеет один авторитетный список полей — producer = consumer]
- **[I-3]** [пример: блокирующие вызовы не в event-loop / потокобезопасность общего стора]

## Ограничения

- [пример: без авто-discovery — регистрация явная]
- [пример: слой представления не содержит бизнес-логику]
